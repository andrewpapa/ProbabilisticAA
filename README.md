# Probabilistic Archetypal Analysis

Python implementation of *Probabilistic Archetypal Analysis*, based on the method described in:

> Seth, S., Eugster, M.J.A. *Probabilistic archetypal analysis*.  
> Mach Learn 102, 85–113 (2016).  
> doi: https://doi.org/10.1007/s10994-015-5498-8  

The implementation in this repository is a Python translation of the MATLAB implementation provided by 
the original authors:

> https://github.com/aalab/paa

The Python implementation is intended to reproduce the functionality of the original MATLAB code. 
This repository is an independent Python implementation and is not an official release of the original authors.

## Installation

Clone the repository:

```bash
git clone https://github.com/andrewpapa/ProbabilisticAA.git
cd ProbabilisticAA
```

Install the package using `pip`:

```bash
pip install -e .
```

## Example

An example Jupyter notebook demonstrating the application of the different PAA approaches to simulated data can 
be found in the `examples/` directory.
